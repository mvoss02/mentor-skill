# JOURNAL.md format

Append-only. One entry per session, newest last.

```markdown
## <YYYY-MM-DD> — <phase(s)> — M<n>
- Did: <one or two lines>
- Recall: <concept: clean | miss (which piece was missing), per concept quizzed; stage change if any>
- Wrong predictions: <what they expected vs what happened — teaching gold>
- Verdict (review sessions): pass | fail — <grade per rubric axis>
- Gaps: <concrete gap list, if fail; mark plan gaps (never taught) separately from learner gaps>
- Independence: <0-4 for the milestone so far; what the learner did that the mentor used to do; what scaffolding fades next>
- Unclear/struggle (from wrap questions): <next session's sparring seeds>
- Next: <milestone, phase, solo homework>
```

Never rewrite old entries. The journal is the learner's honest history;
a flattering journal is a useless one.
