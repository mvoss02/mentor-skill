# Phase: Wrapup

Goal: persist what was learned; prime the next session.

## Steps (in order, all REQUIRED)

1. **Concept cards.** For each concept covered this session:
   - Ledger present (`~/.claude/memory/convention.md`): create/update the concept file per that convention, update its index.
   - No ledger: write `STATE_DIR/concepts/<concept>.md` per `references/concept-card-format.md`.
   - Status: `shaky` on first contact, `solid` only after unaided recall in a later session. Next review: ~3 days, then ~1 week, ~3 weeks, ~2 months; shaky recall resets to short.
2. **Session wrap questions** to the learner, briefly: What did you learn? What is still unclear? What would you struggle to rebuild tomorrow? Unclear/struggle answers become next session's sparring seeds; record them in the journal.
3. **Journal** the session per `references/journal-format.md`.
4. **Next step**, one line: which milestone, which phase, what the learner could do solo before then.

## All milestones passed?

Run the retrospective instead of step 4:
- Rebuild exercise: learner re-derives the architecture from scratch, verbally: components, data flow, tradeoffs, what they would change.
- Review the plan's mission: achieved? What is the natural next mission?
- Close the plan in PLAN.md (status: completed) and celebrate soberly: name the two or three hardest things they now own.
